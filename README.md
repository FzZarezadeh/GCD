


🔢 Recursive GCD Calculator – C# Console App

A simple C# console application that calculates the Greatest Common Divisor (GCD) of two integers using a recursive method. This project demonstrates basic recursion, input handling, and mathematical logic in a clean and readable structure.

---

📦 Features

- User Input:
  - Prompts the user to enter two integers.
  - Parses input and determines the smaller value for recursion.

- Recursive GCD Logic:
  - Uses a custom recursive method to find the GCD.
  - Checks divisibility and decrements until the greatest common divisor is found.

- Console Output:
  - Displays the result in a formatted message.
  - Waits for a key press before closing.

---

🛠 Technologies Used

- Language: C#
- Platform: .NET Console Application
- IDE: Visual Studio or any C#-compatible editor

---

🚀 How to Run

1. Clone or download the repository.
2. Open the solution in Visual Studio.
3. Build and run the project.
4. Enter two numbers when prompted.
5. View the calculated GCD in the console.
